# Icons

## Style

- Lucide-like stroke icons (1.5–2px), monochrome  
- Custom SVG for topology roles when needed  
- **No emoji**

## Semantic colors (rare)

Only status glyphs may use:

- Success `#00E676`  
- Warning `#FFB300`  
- Critical `#FF3D71`  
- Accent `#00B8FF`  

Default stroke: `#94A3B8` / active `#F8FAFC`.

## Topology role dots

Use fills from [`../colors.md`](../colors.md) role table.
