# Backgrounds

## Application mesh

Subtle dark network mesh behind the shell and login — depth without noise.

| File | Use |
|------|-----|
| `network-mesh.svg` | CSS background (preferred, crisp, tiny) |
| `network-mesh.png` | Raster fallback / marketing |
